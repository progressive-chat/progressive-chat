Three things an asking was missing:

- **only what fits is sent.** The window an answerer has now decides where the asking starts: Agora's own preparation stands behind it (limitContext over ContextBudget, with what the model is told and the tools it may ask for taken off the window first). The conversation itself is untouched by it -- every message stays, is drawn as it was, and the tools still read all of them.
- **the settings are said where the question is asked.** The generation rows moved numbers that were read out of the settings and dropped before the body was written; the asking now takes both halves from one place (src/tools.cc, `wanted_of`): temperature, top-p, the ceiling on an answer, the penalties, the thinking and how hard.
- **the anthropic wire asks for thinking.** In the budget this family takes it in, asked of the capability Agora keeps for a model (and nothing said where the model takes no thinking at all); sampling goes quiet beside it, except a top_p in 0.95..1, and the room asked for holds the budget plus the answer.

Tests: `pchat-provider-budget-test` says where the asking starts; `pchat-provider-test` reads the anthropic body back -- budget, room, sampling, and a model that never thought. A probe (tools/probe_asked.mjs) checks the same off the request the page makes.
