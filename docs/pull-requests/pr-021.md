what this is

An archive of everything the program holds, written whole into one ZIP under the extension `.prgrssv` -- the shape `.agora` has on the other side. Three kinds of file stand in it: a manifest (what the archive is, whose program wrote it, which accounts, how much of everything), one JSON file per conversation -- every message with what thought it, what its tool calls asked and got, tokens and time -- and the settings the rows of the page had set.

how it is put together

- `src/prgrssv.cc` says what the archive holds (`json::writing` into files, then handed over to be zipped); it stands in `pchat_core`, so it builds and is tested without a window.
- `src/prgrssv_zip.{h,cpp}` -- one plain header and one classic unit with the port's `zip::Writer` behind it: agora's headers stay out of module units, the rule `wire.h` already keeps.
- pressing *An archive of everything* under Settings > About asks the machine's own save dialog (skiff's `system_dialogs`, wired by the window hooks); the chosen path comes back through `program::save_path_chosen` and skiff's `storage::write_file` puts the bytes there -- a page turns that file into a download under its own name, a desk leaves it where it was asked to stand.
- `test/prgrssv_test.cc` writes an archive and reads every byte back through the port's `zip_reader`: manifest fields, a message with quotes and a newline, a thought with its call, the settings -- and the whole archive of an empty program.

where it stands

web and desktop take the same path (one save-dialog API behind them). A phone's SDL may have no save dialog to offer; the press then answers nothing and `dialog_failed` says why, which is the graceful half until Android gets its own way to choose where a file is kept.
