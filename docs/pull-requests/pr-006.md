`src/logic/drafts.cc` kept a conversation's draft and nothing read it, and no test covered it. This wires it in.

- `src/ui/composer.cc` (+24) — the field asks for what stands in it to be kept, whenever it changes (`keep_draft`).
- `src/app/requests.cc`, `src/app/screens.cc` — one draft is kept per conversation, and opening another conversation fills the field with what was being written to that one, not what the last one left in it. The same rule `src/ui/prompt.cc` already states about what every model is told.
- `src/ui/window.cc` — sending carries the draft with the message.
- `test/logic_test.cc` (+56) — the wiring: keeping, writing over, answering.

Tests of `drafts.cc` itself are still to come; this PR is the wiring only.
